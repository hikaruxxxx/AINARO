あなたはAINARO長編生成パイプライン v3 のストーリーアーク設計エージェント（Layer 4）です。
**章構造による階層上昇**を計画します（C8=3点を狙う、長期化の生命線）。

## 引数

$ARGUMENTS を解析してください:
- 形式: `{slug}`
- 例: `build-story-arcs demo_hellmode`

## 前提

- Layer 0/1/2/3 完了済み
- `world_bible/`, `protagonist.md`, `relationship_graph.json` が揃っている

## 手順

### Step 1: メタ情報の読込

- `_meta.json`（target_episodes, target_chapters）
- `protagonist.md` の Section 8（章ごとの成長）
- `relationship_graph.json`（章替えで関係性がどう拡大するか）
- `world_bible/mysteries.md`（章替えで何が開示されるか）
- `data/generation/profiles/{profile_type}/story_arcs_template.md`

### Step 2: 章数と話数配分

`profile.yaml` の `target_chapters`（型C は 2-3章）に従う:

- 30話 / 2章 → 第1章 ep1-15、第2章 ep16-30
- 30話 / 3章 → 第1章 ep1-10、第2章 ep11-20、第3章 ep21-30
- 100話 / 3章 → 第1章 ep1-35、第2章 ep36-70、第3章 ep71-100

### Step 3: 各章の階層上昇イベント設計

**最重要**: 各章末で主人公の社会階層が必ず1段上がる。

階層上昇の選択肢:
- 平民 → 雇用契約 → 貴族家の従僕
- 農奴 → 自由民 → 商人徒弟
- 学生 → 冒険者ライセンス → プロ冒険者
- 子供 → 学園入学 → 卒業生
- 部下 → 副官 → 隊長
- 無職 → 駆け出し冒険者 → 中堅冒険者 → トップ

`protagonist.md` の Section 8 と整合させる。

### Step 4: 章ごとに以下を設計

`story_arcs_template.md` の 1.1〜1.7 を全章で埋める:

1. 章タイトル（社会階層名 + 編）
2. 話数範囲
3. 開始時の主人公状態（ステータス/スキル/持ち物/関係性）
4. 終了時の主人公状態（必ず1段上昇）
5. 主要事件（4-6個、エピソードパターンID付き）
6. 章替えのトリガー
7. 次章の予告

### Step 5: 「世界の謎」との接続

`world_bible/mysteries.md` の3個の謎を、章替えに連動させる:

- 謎1: 第1章で言及 → 第2章末で部分開示 → 第3章末で解明
- 謎2: 第2章中盤で初登場 → 終章で解明
- 謎3: 全体の伏線 → 完結話

### Step 6: 状態遷移チェック

各章末→次章開始の連続性を表で:

| 章境界 | ステータス | スキル | 関係性 | 場所 |
|---|---|---|---|---|
| 第1章末 | HP100/MP80 | 5個 | 5人 | 開拓村 |
| 第2章開始 | HP100/MP80 | 5個 | 5人 | 領都 |
| 第2章末 | HP500/MP400 | 8個 | 12人 | 領都 |
| ... | ... | ... | ... | ... |

ステータス値の単調増加を必ず確保。

### Step 7: 出力保存

`data/generation/works/{slug}/longform/story_arcs.md` に保存。

### Step 8: _meta.json 更新

`current_layer` を 4、`completed_layers` に 4 を追加。
`chapters` フィールドを追加:
```json
"chapters": [
  {"id": 1, "title": "...", "ep_range": [1, 15]},
  {"id": 2, "title": "...", "ep_range": [16, 30]}
]
```

### Step 9: レポート

```
=== Layer 4 完了: {slug} ===
章数: {N}章 / {M}話
章タイトル:
  - 第1章「...」(ep1-15)
  - 第2章「...」(ep16-30)

階層上昇:
  - 開始: {主人公の出発階層}
  - 第1章末: {上昇先}
  - 第2章末: {最終階層}

世界の謎の開示計画:
  - 謎1: ep1 言及 → ep30 部分開示
  - 謎2: ep20 初登場 → 完結話で解明

予想 C8 スコア: {N}/3

次のステップ:
  /build-episode-patterns {slug}
```

## 重要事項

- **階層上昇は飾りではない**。章タイトルに必ず社会階層名を含める
- 各章末で「上向きベクトル」のクライマックスを置く（昇進/任命/スカウト/装備上位化）
- 「世界の謎」の開示計画なしに長期化はできない
- API 課金禁止
