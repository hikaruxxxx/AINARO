## D. 商品説明 (description_html、KDP 許可タグのみ)

```html
<p><b>Fランクの俺だけに、世界最速ルートが聞こえる。</b></p>

<p>経験値効率2.4倍。隠しドロップ条件、開示。<br>
Sランク探索者が20年かけても辿り着けなかった現代ダンジョンの裏ルールを、頭の中のシステム音声【ナビ】だけが教えてくれる。</p>

<p>ダンジョン適性Fランクの桐生レンは、職業欄すら空白のまま社会の底辺に押し込まれていた。探索者ランクは生涯固定。Fランクは入口整理か雑用で終わる。誰もがそう決めつけていた。</p>

<p>だがある朝、レンにだけ女性の声が響く。<br>
<b>「経験値倍化条件、開示します」</b></p>

<p>誰にも聞こえないナビ。誰も知らない隠しルール。誰も選ばない最短ルート。<br>
Fランクのまま、レンは世界最速のレベルアップ記録を塗り替えていく。</p>

<p>現代日本に出現した管理ダンジョン、未鑑定スキルガチャ、国家直轄のSランク部隊、記録を疑う公社監査室。<br>
底辺認定された少年が、情報とナビだけでランク制度を踏み越える、現代ダンジョン下剋上漫画。</p>

<p><b>全13巻完結予定。横読み白黒漫画、Kindle Unlimited対応。</b><br>
第1巻では、ナビとの最初の取引と、Fランク探索者による最初の記録更新を収録。</p>
```

**設計**: 冒頭から「2.4倍 / 世界最速 / Fランク下剋上 / 俺だけのナビ」を押し、中盤で世界観 (管理ダンジョン/Sランク部隊/公社監査室) を補強、末尾で安心材料 (完結予定/KU 対応/第1巻収録範囲) を提示。

## F. 巻末引きの定型 (各巻ラスト1ページ、a07 全13巻使い分け候補)

1. **記録更新バレ型**: 公社端末に異常値が出る。「Fランクがこの階層を突破？ ありえない」
2. **ナビ新条件開示型**: 勝利直後、ナビが次の爆弾を告げる。「次の経験値倍化条件は、Sランクとの共闘です」
3. **幼馴染照合型**: 灯里が匿名 ID を追う。画面は「該当者なし」、しかし彼女だけが気づく。「この動き、レンだ」
4. **ガチャ未開封暴発型**: 巻末で未鑑定クリスタルが反応。「通常排出テーブル外。固有型スキル候補を検出」
5. **ナビ消滅リスク型**: ナビの声が途切れる。「契約者上限に接近。私の優先順位が下がります」

各巻配分案 (推奨):
- Vol.1: ナビ消滅リスク型 (1巻末で「ナビが消えるかも」を提示し、2巻必読化)
- Vol.2-3: 記録更新バレ型 → 幼馴染照合型 (公社/灯里との接触)
- Vol.4-6: ナビ新条件開示型 (毎巻新スキル/新階層)
- Vol.7-9: ガチャ未開封暴発型 (固有スキル覚醒)
- Vol.10-12: 大規模イベント (制度交渉序章 / 中ボス連戦)
- Vol.13: 完結 (ナビとの最終取引、ランク制度書き換え)
