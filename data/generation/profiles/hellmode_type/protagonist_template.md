# 主人公プロファイル テンプレート（ヘルモード型）

このテンプレートは `/build-protagonist {slug}` で参照される。Layer 2で全項目を埋めて、以後全話で再利用する。

C1=3点を狙う。**全話の地の文と独白の核**になるため、項目を省略しないこと。

---

## 1. 基本情報

- **現世の名前**: ◯◯（固有、本文で多用）
- **現世の種族**: 人間／エルフ／獣人／魔族／その他
- **現世の出生環境**: 例「開拓村の農奴の長男」「没落貴族の三男」「奴隷階級」
- **現世の容姿**: 1段落（目立たない/中の下/特徴的でない、が望ましい）
- **現世の年齢**: 物語開始時点

---

## 2. 前世（最重要）

ヘルモード型の主人公は**前世の人格と執着が現世での行動を支配**する。前世を作り込まないとC1=3点は取れない。

### 2.1 前世の基本
- **前世の名前**: ◯◯（フルネーム）
- **前世の年齢**: 何歳まで生きたか
- **前世の職業**: 例「サラリーマン」「ニート」「OL」「研究者」「無職」
- **前世の死因**: 例「過労死」「通り魔」「事故」「老衰」

### 2.2 前世の趣味・執着（執着の根源）
ここが**主人公人格の核**。具体的に1つ書く。
- **趣味**: 例「ネトゲ廃人（やり込み志向）」「読書（特に異世界小説）」「料理研究」
- **執着の対象**: 趣味の中で何に最も熱中していたか
- **執着の理由**: なぜそれに熱中したか

ヘルモード参考: 山田健一は「ヌルゲー嫌悪、廃ゲーマー、20年前のレベル上げ1ヶ月のMMOへの郷愁」を持つ

### 2.3 前世の不満・憎悪
- **何に不満を抱いていたか**: 例「ヌルゲー化したゲーム業界」「自分の不甲斐なさ」
- **何を憎んでいたか**: 例「効率主義」「楽な道」「上司」

### 2.4 前世の知識
現世で活用する知識を3-5個明示する:
- 例: ゲーム的最適化思考、料理レシピ、ビジネス知識、歴史知識、プログラミング

## 4. 思考パターン

ヘルモード型の主人公は**計算思考または最適化思考**を必須で持つ。

### 4.1 主たる思考パターン（1つ選択）
- [ ] 計算思考: 数値・ステータスで判断する
- [ ] 最適化思考: 効率・組み合わせで最善手を探す
- [ ] 検証思考: 仮説→実験→結果のサイクルを回す
- [ ] 慎重思考: リスクを徹底的に避ける

ヘルモード参考: 山田健一は「最適化思考＋検証思考」のハイブリッド

### 4.2 思考パターンの本文への現れ
内的独白でどう表現するか、3-5個の例文を書く:
- 例: 「（このスキル経験値の上がり方なら、あと◯◯回検証すれば仕様が確定するな）」
- 例: 「（攻撃力◯◯ではダメか。素早さに振り直すか）」
