# Phase A 3作品 コンセプト草案 v1

2026-05-01 作成。Phase A (KDP+KU 検証フェーズ) で並行制作する3作品のコンセプト草案。

各作品は世界観・画風が完全独立。読者層は「異世界なろう系」という大カテゴリ下で重なるが、サブジャンルは別。

決定が必要な項目: タイトル / 主人公の最終像 / 1巻のクライマックス / ヒロイン or 重要相棒キャラ / 商業フック (なろう系で「読者が刺さるツボ」)

---

## 作品 1: ダンジョン探索系

**仮タイトル**: 「**底辺鑑定士の地下迷宮無双**」 / 「**追放された俺だけが知る、ダンジョンの正解**」

- **art_style**: `manga_bw_seinen_dark` (Berserk/Vagabond 系劇画)
- **主人公**: シノザキ・カナデ (16-17歳男性) — 元勇者パーティの鑑定士。戦闘力は低いが「真の鑑定眼」で隠しスキル/隠し階段/モンスターの真価を見抜ける。パーティから「お荷物」と追放された後、独力でダンジョン深層を制覇していく
- **主要相棒**: 「真銀の翼」という冒険者ギルドのソロ受付嬢 (20代、過去にパーティ全滅を経験、主人公の力を最初に見抜く理解者)
- **1巻クライマックス**: 1〜3階層を独力踏破、3階層ボスの **大型ミノタウロス** を「鑑定眼で見抜いた弱点」で撃破。元パーティの仲間が4階層で苦戦中の現場に主人公だけが先到着するシーンで引き
- **読者期待 (ジャンル定石)**: ザマァ系 + 鑑定スキルチート + ソロ無双 + 美人女性キャラの理解者
- **商業フック**: 「無能と思われた鑑定士の本当の能力」+「元仲間の絶望」+「下層に行くほど真価を発揮する逆転構造」
- **連載予想**: 5-10巻 (ダンジョン階層拡張で章を切る)

---

## 作品 2: 転生貴族・領地経営系

**仮タイトル**: 「**辺境追放の三男ですが、前世の経営手腕で領地を救います**」 / 「**転生先は破滅寸前の辺境伯。現代経営術で逆転します**」

- **art_style**: `manga_bw_shoujo_classic` (Rose of Versailles 系)
- **主人公**: アルベール・フォン・ハーゼンベルク (19歳男性) — 前世は現代日本の経営コンサル/税理士。三男として継承権なし、辺境の小さな伯爵領を継がされた。前世知識(複式簿記/税制改革/作物輪作)で領地改革
- **ヒロイン**: 領地で知り合った少女騎士アンナ (17歳、剣の腕は男以上、貴族家次女、主人公の最初の理解者)、もしくは婚約者として送られてきた敵対家系の令嬢 (14歳、悪役令嬢系の毒舌だが本質は優しい)
- **1巻クライマックス**: 領地に蔓延る盗賊団の壊滅 + 隣領貴族との初の交易成功 + 中央からの査察使を見事もてなして「辺境の宝石」と評される
- **読者期待 (ジャンル定石)**: 内政無双 + 異世界×現代知識のギャップ + 民との交流による主人公の人柄醸成 + 中央政治への進出予兆
- **商業フック**: 「税理士の細かい知識を異世界で使う面白さ」+「辺境を変えていく成長物語」+「貴族社会の華やかさ (画風活用)」
- **連載予想**: 8-12巻 (領地拡大→中央政治→大陸政治の三部構成)

## 3作品の同時展開時の注意

| 観点 | 配慮事項 |
|---|---|
| ペンネーム | 同一にする?レーベル展開的にすると統一感ない。**仮: 統一ペンネーム「森光ヒカル」+ レーベル名「Novelis」を表紙に表記** |
| 公開順 | 3作品同時より、1ヶ月ずつ時差公開推奨 (Amazon ランキング独占を防ぐ + 読者の購買サイクル平準化) |
| 表紙テイスト | 画風が異なるので、表紙はシリーズ統一感を出すために **共通フォーマット (タイトル位置・帯デザイン)** を作る |
| 1巻冒頭 | 3作品とも「3ページ以内に主人公の魅力 + ジャンル定型」を見せる構成にする |

## 制作優先順位の推奨

1作目から始めるなら、**作品3 (現代ダンジョン)** を最初にする推奨理由:
- 現代背景は AI が最も得意 (建物・服装・小物の参考データが豊富)
- KU 読者層が最厚 (Solo Leveling 系の流れ)
- 1巻完成までの工程的リスク最小

2作目は **作品1 (ダンジョン探索)**、3作目は **作品2 (転生貴族)** の順序が、画風難易度の昇順で安全。
