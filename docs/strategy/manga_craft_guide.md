# 漫画作法ガイド v2 — 商業ラノベコミカライズの完全分析

2026-05-01 v2 完全版。kindle-test-1「現代ダンジョンで最強になる物語 (缶詰ガチャ) Vol.1」全156ページを精読して抽出した作法体系。

Phase A 制作で **storyboard-builder のプロンプト** および **F-2 ページ生成プロンプト** に反映する。

---

## 大原則: panel は物語を進める単位

漫画は「シーンを羅列するパンフレット」ではない。各 panel は:
- **読者を物語に引き込む 1 つの感情ビート**
- **次の panel への期待を作る**
- **主人公の感情・気付き・モノローグを 1 つだけ運ぶ**

## 1巻全体の章構成 (kindle-test-1 = 5話・156ページ)

| 章 | ページ数 | 役割 |
|---|---|---|
| 表紙・目次・扉 | p001-005 | メタ情報、マスコットがメタ説明 |
| 第1話「小遣い稼ぎにもならない」 | p006-038 | 世界観establishing、主人公の地位、缶詰ガチャ初遭遇 |
| 第2話「自分専用のダンジョン」 | p039-066 | PD覚醒、家族との対比、PD説明 |
| 第3話「スライム酒」 | p067-098 | 経済の話、ヒロイン再会、レベルアップシステム |
| 第4話「詳細鑑定」 | p099-126 | スキル進化、二階層攻略、ニュース化 |
| 第5話「ダンジョンの異変」 | p127-154 | 海外編、強敵遭遇、五階層異変 (cliffhanger) |
| 巻末 | p155-156 | 奥付 |

各話 ≈ 28-32ページ × 5話 = 1巻160ページ。

### 各話の典型構造 (10-15panel/page × 16-20panel)

| ビート | ページ位置 | 役割 |
|---|---|---|
| 1. 章扉 | 1ページ目 | 章タイトル + 主人公全身 + マスコット |
| 2. 復帰establishing | 2-3ページ目 | 前話からの流れを再導入 |
| 3. 中心エピソード (前半) | 4-12ページ目 | 設定説明・新要素導入 |
| 4. 中心エピソード (後半) | 13-22ページ目 | 主人公の挑戦・葛藤・成長 |
| 5. 山場 | 23-26ページ目 | 戦闘 or 重要な発見 |
| 6. 余韻と引き | 27-32ページ目 | 結果 + 次話への期待 (cliffhanger) |

## キャラ造形パターン (異世界なろう系)

### 主人公 (壱野泰良)
- **外見**: 黒髪短髪、整った顔、無表情寄り、現代制服 or 私服
- **属性**: 一見地味、内に秘めた強さ、「最低底」から「最強」へのギャップ
- **役割**: クール冷静、独白で読者と感情を共有
- **キャラ枠**: 「壱野泰良 苦手なコト イカサマ扱い」のように属性提示

### ヒロイン (牧野ミルク)
- **外見**: 茶髪ロング (ハート型ピン)、大きな目、ふわっとしたスカート、ニーソ
- **属性**: 主人公の幼馴染、家族の影 (父が探索者)、応援役
- **役割**: 主人公の動機キャラ「私もすぐ追いつく」
- **登場頻度**: 1巻で5-8回、距離感を保ちつつ徐々に密接化

### 親友 (秦良)
- **外見**: 金髪 + リボン、軽いタイプ
- **属性**: 主人公とは逆の感情ベクトル (爆発・大ハシャギ)
- **役割**: 温度差で主人公を引き立てる、コメディ呼吸を作る

### 妹 (青木)
- **外見**: ポニーテール、丸い目、丸い顔
- **属性**: 主人公にツッコミ役、配信者として活動
- **役割**: 兄妹関係の自然さで日常感

### マスコット (PD)
- **外見**: 白くて丸い、簡易顔
- **属性**: PDの守護者、メタ的なツッコミ
- **役割**: 設定説明をジョークで緩める、温度差ペアの軽担当

### 父 (秦良)
- **外見**: 髭、グラサン、ガッシリ
- **属性**: 主人公を温かく見守る
- **役割**: ドロップ品を父に渡す = 異世界が現実に持ち込まれる感

### 敵チーム (ジャック等)
- **外見**: 白髪、グラサン、戦闘服
- **属性**: ランキング王、海外
- **役割**: 別ロケーションで世界観の脅威を示す

## 1ページ内の panel 構成 (典型パターン 5種)

### パターン A: 「establishing → 中心 → 反応」 (3-5panel/page)
1. 上段大コマ: ロケの引き
2. 中段: 主人公 + 状況
3. 下段: 主人公のリアクション or 引き

### パターン B: 「3段ティア構成」 (5-7panel/page)
1. 上段: 1コマ大 (establishing)
2. 中段: 2-3コマ (会話・動作・反応)
3. 下段: 1-2コマ (引き or 締め)

### パターン C: 「アクション分割」 (4-6panel/page)
1. 上段: 構え or 接近
2. 中段: 攻撃の決定的瞬間 (大コマ)
3. 下段: 結果 + 主人公表情

### パターン D: 「会話シーン」 (5-7panel/page)
1. 上段: 引きで2人の位置関係
2. 中段: クローズアップ交互 (キャラA → キャラB)
3. 下段: 締めの結論 or 引き

### パターン E: 「アイテム解析」 (4-6panel/page)
1. アイテム単体大コマ
2. 説明枠 (鑑定結果テキスト)
3. 主人公のリアクション
4. (補足: 関連情報 or 値段枠)

## 視覚要素の作法 (10要素)

### 1. キャラ紹介ボックス
**実装**: 四角枠で「名前 + 属性 + 短い特徴」
**例**: 「壱野泰良 苦手なコト イカサマ扱い」「ジャック ダンジョン探索者 換金額・世界ランキング王」
**頻度**: 重要キャラ初登場で1回。1巻で5-8回

### 2. 状況注釈ボックス
**実装**: 「※息子の初バイト帰りのノリ」のような状況説明
**頻度**: 1ページに0-1個

### 3. ステータス画面 panel
**実装**: 透明矩形フレーム + テキスト「壱野泰良: レベル1 体力15/15 攻撃3 幸運100 スキル無」
**頻度**: 章末・章頭で必ず1回更新表示

### 4. アイテム説明枠
**実装**: 灰色背景の矩形枠でアイテム名・効果・価格を別レイヤー記述
**例**: 「(黒)Dメダル 換金額 一枚50円」「炎の石 装備の属性を変化させる石 販売所買取¥320,000」

### 5. SNS / 配信動画 panel
**実装**: スマホ画面の矩形フレーム、Twitter/X 風レイアウト、ニュース速報、再生数 (10万回!?)
**頻度**: 主人公の社会的影響を示す重要場面で

### 6. 効果音 (オノマトペ)
**実装**: 大きな手描き文字を panel 内に配置
**例**: 「ペタペタ」(足音)、「キン!」(警告)、「しばかれるッ」(主人公の予感)、「ブシュ!」(攻撃)、「ジュー」(料理)
**注**: SVG重ね前提のため画像生成では描かず、ネーム段階で記録、後付け

### 7. 章扉
**実装**: 1ページ全面に主人公全身 + マスコット + 章番号 + 章タイトル
**例**: 「§2話 自分専用のダンジョン」

### 8. 章末ロゴ
**実装**: タイトルロゴ「KOUN KANDUME GACHA」を章末に配置で区切り

### 9. 大コマ (extra_large / splash)
**実装**: ページの半分以上を占める panel
**用途**: 強敵登場、大ロケ establishing、必殺技解放

### 10. 大ゴマ俯瞰 (spread / wide)
**実装**: 全面1コマで建築・空間・群衆を俯瞰
**用途**: 章中盤の世界観質感、迷路全景

## 感情演出の作法 (8要素)

### 1. 主人公の独白
**実装**: 雲型吹き出し (実線でない、点線・破線・透過枠)
**頻度**: ほぼ毎ページ1回以上
**例**: 「俺の幸運値の初期値は100だった」「もっと強くならなくちゃ」

### 2. 派手 vs 地味のギャップ
**実装**: 1ページで「期待 (魔物との死闘・財宝)」 vs 「現実 (時給100円・100円おにぎり)」を併置
**例**: page_0009 で友人「魔物との死闘! レベルアップ! 財宝の発見!...」 → page_0011 で主人公「30分待って時給100円...マジなんだな」

### 3. 温度差ペア (友人爆発 vs 主人公冷静)
**実装**: 隣接 panel で 友人/相棒の感情爆発と主人公の無表情を並べる
**例**: page_0013 で友人「稼ぎたい!! 楽して稼ぎて!!!!」(全身崩壊) → 主人公 (テーブルに肘、無表情)

### 4. マスコット軽 vs 主人公重
**実装**: マスコット (PD) の軽い台詞 ⇔ 主人公の深刻表情を同panel内に
**例**: page_0042 マスコット「うっかり作っちゃった階段付き落とし穴☆」 ⇔ 主人公「母さんにコイツがバレたら...!」

### 5. 顔以外の部位で感情
**実装**: 足元・手・背中のクローズアップで間接的に感情を語らせる
**例**: page_0044 母の浮いた足 = 落ちる前の危機

### 6. 連続吹き出し (焦り/動揺)
**実装**: 「やばい」「これ」「え?」を1コマ内に複数配置
**用途**: パニック・驚愕・焦り

### 7. 写真フレーム / 過去回想
**実装**: panel内に額入り写真や思い出シーン (過去の女子姉妹等)
**用途**: 主人公の動機・過去の想いを示す
**例**: page_0027 主人公の独白「俺は...」+ 写真フレームに姉妹

### 8. 表情の極端化 (ギャグ顔)
**実装**: 友人の表情爆発、瞳ハイライト爆増、口デフォルメ
**用途**: コメディ部分でテンションを爆上げ
**例**: 青木「D映像編集者の資格を取る!」(瞳キラキラ + 大口)

## panel 連結パターン (15種)

### 物語駆動の繋ぎ
1. **establishing → 主人公 → 主人公感情** (場面転換、章頭)
2. **全体 → 個 → 反応** (新キャラ/新場所登場)
3. **3段階深掘り (緊張)** = 気付き → 状況 → ピンチ深刻化 (page_0042-0044)
4. **expectation → reality** = 期待 → 現実落差 (page_0008-0011)
5. **会話A → 会話B → 結論** (シンプルな会話シーン)
6. **アクション → 効果音 → 結果** (戦闘の動作分割)
7. **アイテム → 説明枠 → リアクション** (アイテム解析)
8. **問題提示 → 検討 → 決断** (主人公の動き出し)
9. **ステータス画面 → 主人公独白 → 行動** (レベルアップ後の意気込み)
10. **電話シーン → 反応 → 決意** (キャラ間の距離感)

### 視覚的繋ぎ
11. **大コマ → 連続小コマ** (ピーク → 散発)
12. **連続小コマ → 大コマ** (積み重ね → 爆発)
13. **クローズアップ連鎖** (顔 → 手 → 別キャラ顔)
14. **シルエット → クリア** (謎 → 解明)
15. **静 → 動 (smash cut)** (日常 → 異変)

## 設定説明の作法

### ナレーション禁則
**避ける**: 説明用ナレーション枠を多用すること。読者を退屈させる。

### 会話で世界観説明 (推奨)
**実装**: キャラ同士の何気ない会話で設定を伝える
**例**:
- page_0007 「Dができる前からダンジョンって呼ばれていたらしいぜ」
- page_0009 友人「魔物との死闘! レベルアップ! 財宝の発見!...なくない?」(派手期待 + 失望)
- page_0018 マスコット「魔物を倒して開いたとか」「十年持ってたら開いたとか」(D缶の説明)

### マスコットによる説明
**実装**: マスコット (PD) が読者代理として「なんで?」と問い、主人公や別キャラが答える
**例**: page_0033 PD「PDって何」 → 説明枠「アクティブスキル...」

### ステータス画面 / アイテム枠での説明
**実装**: 視覚的UIで読者に直接読ませる
**例**: page_0024 で「壱野泰良: レベル1 体力15/15 攻撃3 幸運100 スキル無」を全画面表示

### 「危険警告」風の注釈
**実装**: 「決して噛んではいけない」のような注意喚起調の説明
**例**: page_0144 「スキル玉:舐めるとスキルを覚える 決して噛んではいけない 偽装されている」

## 場所/時間の転換作法

### 場所転換の establishing 必須
**実装**: 前のシーンが切れたら、新シーンの最初の panel は **必ず ロケ全体の引き** で「ここはどこ」を読者に伝える
**例**: page_0020 自宅外観 → 入室シーン → 部屋

### 時間転換 (timeskip) の表現
**実装**: 章扉、SNS panel、ニュース速報、季節モチーフ (桜・雪・GW表記) で表現

### 同一場所の継続
**実装**: 場所を保ったまま panel を進める場合、背景の小物・キャラ位置の連続性を保つ

## 戦闘シーンの作法

### 動作の分割
**実装**: 1つの動作を3-5panelに分割
1. 構え or 接近 (panel 1)
2. 中間動作 (panel 2)
3. 命中の決定的瞬間 (大コマ panel 3)
4. 結果・効果音 (panel 4)
5. 主人公表情 / 敵のリアクション (panel 5)

### 弱点描写
**実装**: 戦闘前 or 中盤で「弱点は 顎の」のような明示で読者にバトルロジックを伝える

### 効果音活用
**実装**: 「ガッ」「ドッ」「ブシュ!」「ヌルッ」を動作・命中に必ず添える

### 必殺技解放
**実装**: 大コマで一気にエフェクト爆発、シルエットの強敵 → 主人公の覚醒
**例**: page_0154 「2時間に1回きりのとっておき」「魔法」「解放」

## 1ページの密度リズム

### 推奨配分 (5-7 panel/page)
- 1 panel: establishing or 大ゴマ (高密度)
- 2-3 panel: 中ゴマで会話・反応 (中密度)
- 1-2 panel: クローズアップで感情 (低密度、白背景)
- 1 panel: 引き or 場面転換 (中密度)

### 必須リズム
- 各ページに **少なくとも 1 panel は 50% 以上ピュアホワイト** (silence_panel A 評価の要素)
- 各ページに **少なくとも 1 panel は高密度** (focus を作る)

## storyboard-builder への反映指針

### 既存 SCHEMA に追加すべきフィールド

```typescript
// 既存
purpose: string;                  // このコマで読者に伝えること
change_from_prev: string;         // 直前コマからの変化
link_to_next?: string;            // 次コマへの繋ぎ
visual_focus: string;             // 絵の中で目を引かせる要素
narrative_function: NarrativeFunction;
cut_type?: CutType;

// 追加すべき (v2)
intro_box?: { name: string; attribute: string; special_trait?: string };  // キャラ紹介ボックス
status_window?: {                                                          // ステータス画面 panel
  level: number;
  hp: string;
  attack: number;
  // ...
};
item_card?: {                                                              // アイテム説明枠
  item_name: string;
  description: string;
  price?: string;
};
sound_effect?: string;                                                     // オノマトペ (SVG後付け)
sns_overlay?: { platform: "twitter"|"news"|"app"; content: string };       // SNS/動画 panel
monologue?: string;                                                        // 主人公の独白 (雲型吹き出し)
emotion_burst?: "ghost_face"|"sweat_drop"|"vein_pop"|"gritted_teeth";      // ギャグ顔表現
tone_contrast?: "vs_mascot"|"vs_friend";                                   // 温度差ペア指示
```

### F-2 page_one_shot プロンプトへの反映指針

1. **panel description は「主人公の感情ビート + 1 情報」**
2. **Page scenario は章構成 (establishing→中心→山場→余韻) で指示**
3. **キャラ感情を毎 panel に**: 「Each panel must include the protagonist's expression / monologue / reaction」
4. **会話で設定説明**: 「Setup info MUST be delivered via casual character dialogue, NOT narration boxes」
5. **マスコット温度差**: 「Include at least one panel where the mascot's lighthearted line contrasts with the protagonist's serious expression」
6. **派手 vs 地味のギャップ**: 「Each page must include one moment of expectation/reality contrast」
7. **密度のリズム**: 「At least one panel = 50%+ pure white. At least one panel = densely rendered focal point」
8. **顔以外の部位**: 「For tense moments, use close-ups of feet, hands, or backs to convey emotion indirectly」

Phase A 制作の品質チェックに「原作の構図・キャラデザを直接複製していない」目視確認を含める。

## 学習結果サマリ (kindle-test-1 全156ページ精読)

- 抽出した作法: **80+ 要素** (キャラ造形5、視覚要素10、感情演出8、panel連結15、設定説明4、場所転換3、戦闘5、密度リズム2、章構成6、典型panel構成5、その他)

- Phase A 制作のベストプラクティスは本ガイドに準拠して storyboard-builder のプロンプトを再構築すること
