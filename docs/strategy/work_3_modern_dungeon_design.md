# 作品3「東京迷宮: 最弱探索者の覚醒」設計書 v0.1

Phase A 1作目として制作する作品の詳細設計。Pilot 8 (modern-dungeon-pilot) の結果から世界観・主人公・3代表シーンが漫画として成立することを確認済み。

| 項目 | 内容 |
|---|---|
| **仮タイトル** | 東京迷宮: 最弱探索者の覚醒 |
| **ジャンル** | 異世界なろう系 / 現代ダンジョン (`modern_dungeon`) |
| **art_style** | `manga_bw_seinen_urban` (Solo Leveling × Tokyo Ghoul 系) |

## 主要キャラクター

### 主人公: 立花 陸 (タチバナ・リク)
- **年齢**: 24歳男性
- **職業**: 派遣社員 (本業) + ダンジョン探索者 (副業、最弱ランク E)
- **外見**: 中肉中背、短い乱れた黒髪、鋭い疲れた瞳、現代ストリートファッション (黒フードジャケット+プレーンシャツ+黒スリムジーンズ+履き古したスニーカー)
- **性格**: 一見冷静沈着、無感動を装うが内面に強い意志。現状への倦怠と微かな野心
- **能力 (覚醒前)**: ダンジョン浅層で薬草採取で月収10万円程度。最弱ランクE
- **能力 (覚醒後)**: 隠しスキル「ステータス再振り」 — 自身のステータス値を任意配分し直せる。死亡寸前のリスクで覚醒
- **発言の少ない主人公アーキタイプ** (ソロ無双系)、心情はモノローグで描写

### ヒロイン: 桐島 玲 (キリシマ・レイ)
- **年齢**: 22歳女性
- **職業**: 国家公認探索者ランクA、政府機関「ダンジョン管理局」職員
- **外見**: 短い黒髪、シャープな目、政府機関的なロングコート (黒+赤襟)、タクティカルサイドアーム携帯
- **性格**: クール、職務に忠実だが情に厚い。リクの覚醒を最初に感知
- **役割**: リクのスカウト、政府機関側のキャラ、後にパートナー
- **本作の女性主要キャラ**: 1巻末で接近、2巻でパートナー確定

### 旧友/日常パートのアンカー: 神尾 亜紀 (カミオ・アキ)
- **年齢**: 24歳女性
- **職業**: 大学院生 (社会学専攻)、非探索者
- **外見**: 茶色のロングヘア、丸い眼鏡、カジュアル服
- **役割**: リクの幼馴染、日常パートの会話相手、覚醒後リクが「失うもの」の象徴
- **登場頻度**: 1巻で2-3話、リクが覚醒の影響で日常を犠牲にし始める伏線

### 敵対者 (1巻ボス): 黒衣の男「番号77」
- **年齢/性別**: 不明 (1巻では背中・シルエットのみ)
- **所属**: 反政府組織「夜行」(ヤコウ)、政府ダンジョン管理局と対立
- **役割**: リクの覚醒を狙う組織側のリクルーター
- **1巻末**: リクの能力に興味を持ち接触してくる、2巻冒頭でリクの選択を迫る

## 1巻のプロット骨格

### 全話数構成 (8話 × 各20-25ページ = 計170-200ページ)

| 話 | タイトル案 | ページ数 | クライマックス |
|---|---|---|---|
| 1話 | 「派遣と薬草と最弱E」 | 24p | 派遣会社の朝→ダンジョン1階層の薬草採取→深層に落下しかけて生還、何かに見られた予感 |
| 2話 | 「ある日のレイド」 | 22p | 新宿駅前で中型モンスター侵攻、リクは民間人として巻き込まれる、レイの初登場 (彼女が制圧) |
| 3話 | 「死にかけて見えた数字」 | 24p | 浅層の暴走モンスターに殺されかけ、覚醒の瞬間。ステータスHUD初出現 |
| 4話 | 「再振り」 | 22p | スキル理解、独学で実験。アキとの日常会話、覚醒を隠す葛藤 |
| 5話 | 「2階層」 | 26p | 単独で2階層に挑戦、初の中型モンスター撃破。ギルドの注目 |
| 6話 | 「3階層と中ボス」 | 24p | 3階層攻略、初のパーティメンバー候補と遭遇 (敵対するか共闘するか) |
| 7話 | 「新宿異変」 | 26p | 1巻クライマックス: 新宿駅前で大規模ダンジョン暴走。覚醒したリクが単独制圧。レイ目撃。TVドローン記録 |
| 8話 | 「数字の向こう側」 | 22p | アキとの距離が広がる、レイから接触の予兆、ラストシーンで黒衣の男「77」が現れる |

### 1巻のテーマ・メッセージ

「**最弱E が見出した『再分配』の力**」 — 努力と才能の物語ではなく、「与えられた手札の使い方」の物語。読者層 (派遣・低賃金で社会の底辺感がある層) の自己投影を狙う。

### 1巻の引き

8話末尾のラストコマ: ダンジョン入口に立つ黒衣の覆面の男 (番号77) のシルエット、「君の数字、もっと自由に振れる場所がある」というセリフ。2巻に続く。

## 視覚設計

### 1巻で繰り返し描写するモチーフ
- **派遣会社の蛍光灯と時計** (リクの社会的位置)
- **100円コンビニのおにぎり** (経済的窮乏の象徴)
- **新宿駅東口・南口・スクランブル交差点** (現代Tokyoの記号)
- **ダンジョン入口の政府サイン** (現代×異世界の境界)
- **ステータスHUD** (覚醒の象徴、SVG重ね前提で空欄)
- **薬草採取バスケット** (1巻冒頭のリクの装備、3話以降は捨てられる象徴)
- **アキの眼鏡** (失われていく日常の象徴)

### 各話の主要ロケ
- 派遣会社オフィス (1話冒頭)
- 新宿駅周辺 (1, 2, 7話)
- 1階層ダンジョン (1, 4話)
- 2-3階層ダンジョン (5, 6話)
- アキの大学/カフェ (4, 8話)
- レイの政府機関 (2話、7話以降)

### 画風統制
- art_style = `manga_bw_seinen_urban` で全話統一
- 日常パート: 線細め、トーン多め (現代日本リアル)
- ダンジョンパート: ベタ濃い、ハッチング多用 (異世界感)
- バトルシーン: 速度線・効果線・大ゴマ多用
- ステータスHUD: 必ず矩形枠のみ (中身はSVGで後注入)

## 制作工程予定

| フェーズ | 期間 | 作業内容 |
|---|---|---|
| 1. キャラ・ロケ Bible 構築 | 1週間 | 4キャラ・5ロケのBible登録、参照画像生成 |
| 2. プロット骨格細部詰め | 1週間 | 8話分の plot 詳細化、各話の beat列確定 |
| 3. 1話ネーム生成 + 検証 | 1週間 | generate-storyboard.ts で1話、レビュー |
| 4. 1話ページ生成 | 2週間 | F-2 主体で1話 24p 生成、F-1 で重要ページを精緻化 |
| 5. 吹き出しSVG重ね + 校正 | 1週間 | bubble/vertical/typesetter.ts で1話組版 |
| 6. 2-8話の量産 | 8-12週間 | 1話あたり 1-1.5週間ペース |
| 7. 表紙・奥付 | 1週間 | KDP入稿用パッケージ |
| 8. 1巻 KDP 入稿 + 校正サイクル | 2週間 | KDP Print 用PDF/X-1a + 電子書籍ePub |

**合計**: 17-21週間 (4-5ヶ月) で 1巻完成。Phase A 全体 (3作品×2巻) を 12-15ヶ月で達成可能。
