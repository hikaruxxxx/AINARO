## ジャンル必須要素 (L1 MUST 強化)

### 1. 前世知識の活用 = 「気付き → 試行 → 効果」3 panel
前世知識を使う場面では:
- panel 1: 主人公の気付き (独白「これは…前世の」)
- panel 2: 試行 (具体的な行動)
- panel 3: 効果 (周囲の驚き or 結果)

### 2. 前世の独白を頻繁に
主人公の独白 (`30_scenes/monologue.md`) は **前世の記憶 / 執着** を含めることで
「異世界転生」の重さを担保する。1 話に 2-3 回。

### 3. チートスキル使用 = 大コマ + 効果音爆発
チートスキル (魔法・術式・固有能力) の使用は **必殺技扱い**。ページの 50% 以上の
大コマ + エフェクト爆発 + 効果音 (`30_scenes/combat.md` の climax 作法準拠)。

---

## ジャンル推奨要素 (L2 SHOULD 強化)

### 1. 中世ファンタジー世界観の establishing
- 城・神殿・貴族・剣・馬車・酒場
- ダンジョンよりも **村 / 街 / 領地** の establishing が多い
- 1 巻冒頭 1-3 ページで「ここは異世界」を明示

### 2. 周囲のキャラの驚きで主人公の凄さを示す
チートを使う場面では、主人公でなく **周囲のキャラの驚き** で凄さを表現:
- 「これは…!?」(驚愕)
- 「ありえない…こんな魔法…」
- 「貴族でもこれはできないはず…」

主人公自身が「俺の力は凄い」と独白するより 3 倍効果的。

### 3. ステータス UI の世界観整合
- 「魔力」「ステータス開示」は神官の鑑定 or 神器に紐付ける
- 現代風のスマホ UI ではなく、**羊皮紙 / 魔法陣 / 結晶** で表現
- ステータス画面の枠デザインが modern_dungeon と違う

### 4. 領地経営型の場合
- 領地の **マップ** を 1 巻に 1-2 回 establishing
- 内政 (税・人口・収穫) の数値を **羊皮紙 UI** で表示
- 臣下との会話で経営判断を伝える (`30_scenes/dialogue.md`)

## ジャンル禁則

### 1. 現代要素を出さない
スマホ・SNS・ニュース速報は使わない (前世のフラッシュバックを除く)。
代わりに **噂話 / 酒場 / 宮廷** で社会的反応を表現。

### 2. SNS panel を入れない
`30_scenes/social_reaction.md` の SNS / 配信 / ニュース速報は **使用禁止**。
代替は:
- 「噂話」(酒場の客同士の会話)
- 「宮廷の議論」(貴族同士の対話)
- 「冒険者ギルドの掲示板」

### 3. 主人公の自慢独白
主人公自身が「俺の力は凄い」と独白するのは弱い。周囲の驚きで示す。

---

## 失敗パターン (isekai_tensei_cheat 特有)

- **前世独白の薄さ**: 1 話に 1 回以下だと "なぜ転生したか" が忘れられる
- **チート使用の中ゴマ化**: 必殺技扱いせず中ゴマで処理するとカタルシス消失
- **establishing 不足**: 異世界の景観 (城・神殿・村) を冒頭で establishing
  しないと "ここはどこ" 不明
- **ステータス UI の現代化**: 羊皮紙 / 魔法陣でなくスマホ風 UI を使うと
  世界観が崩れる

---

## 領地経営型の追加注意

転生貴族 / 領地経営系では **戦闘より内政** が中心。ジャンル内サブタイプ:

### 戦闘比重少なめ・内政比重高め
- `30_scenes/combat.md` の使用は 1 巻に 1-2 回
- 代わりに **会議 / 商談 / 視察** が中心場面 (`30_scenes/dialogue.md` 強化)
- 領地マップ establishing が 1 巻に 3-5 回

### マップ / 図表の活用
- 領地マップ panel
- 内政指標の数値表 (人口・収穫・財政)
- 系統図 (家系図・組織図)

これらは羊皮紙 / 木板 UI で。
