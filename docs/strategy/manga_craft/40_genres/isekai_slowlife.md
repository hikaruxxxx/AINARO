# 40. genre: isekai_slowlife — 異世界スローライフ

genre_id: `isekai_slowlife`
作品例: (Phase A 候補外 — 将来の選択肢として stub のみ)

異世界転生だがバトルではなく **スローライフ / 生活感** を主軸にする系統。
`30_scenes/` の universal な作法に **追加 / 強化** する形で適用する。

---

## 既存コードとの対応

`src/lib/manga/storyboard-v2/craft-guide-directives.ts` の `GENRE_DIRECTIVES["isekai_slowlife"]`
と整合させること:

```typescript
isekai_slowlife: [
  "【isekai_slowlife】生活感 panel (食事/家事/会話) を主軸に。戦闘 panel は最小限",
  "【isekai_slowlife】街並み/季節/天候の establishing で温度を作る",
],
```

---

## ジャンル必須要素 (L1 MUST 強化)

### 1. 生活感 panel (食事 / 家事 / 会話) を主軸
1 ページの 50% 以上を生活感 panel に充てる:
- 食事シーン (材料・調理・食卓・反応)
- 家事 (掃除・洗濯・修繕)
- 軽い会話 (家族・隣人・店主)

### 2. 街並み / 季節 / 天候の establishing
1 話に **2-3 回** establishing 大コマ。村・市場・自宅・畑・森のうち
複数を循環させる。

### 3. 戦闘 panel は最小限
1 巻で戦闘は 0-1 回。必要なら短い (1 ページ以内) に圧縮する。

---

## ジャンル推奨要素 (L2 SHOULD 強化)

### 1. 食事描写の充実
- 食材の出所 (狩り・採集・買い出し)
- 調理プロセス (3-5 panel に分割)
- 食卓の引き
- 食べる表情 (笑顔・満足)

これは [tone_profile = light_recovery](../00_principles.md) の典型 directive
「S3 食事 / S4 服装 / S7 建築 の軽い充実」に対応する。

### 2. 季節の循環
1 巻で 2-3 季節を経過させる。各季節の establishing で温度差を作る。

### 3. 隣人 / 商人キャラとの関係
温度差ペアでなく、**温度近接ペア** で穏やかな対話を作る。

### 4. マスコット軽 vs 主人公穏やかの対比
`30_scenes/monologue.md` の「マスコット軽 vs 主人公重」を、ここでは
「マスコット騒ぎ vs 主人公穏やかな笑顔」で和らげる。

---

## ジャンル禁則

### 1. 戦闘の大コマ濫用
必殺技解放のような大コマは入れない。物語のトーンを破壊する。

### 2. ステータス画面 / アイテム説明枠の濫用
ゲーム系 UI を入れすぎると "ゲーム実況" になり、スローライフのトーンが消える。
1 巻に 1-2 回 (キャラ習得時のみ) まで。

### 3. SNS / 配信 panel
中世ファンタジー世界観のため使わない。

### 4. cliffhanger の強敵シルエット
大きな脅威の cliffhanger は不要。各話末は **小さな次への期待** (新しいレシピ /
明日の予定 / 季節の変化) で十分。

---

## 失敗パターン (isekai_slowlife 特有)

- **生活感 panel 不足**: 食事 / 家事 / 会話の panel 比重が 30% 以下だと
  "スローライフでない" 印象に
- **establishing 単調**: 自宅ばかりで街並み / 畑 / 森を出さないと閉塞感
- **戦闘の混入**: 1 巻で 2 回以上戦闘があるとトーンが破綻
- **温度差ペアの過剰使用**: 爆発キャラとの温度差を毎ページ作ると賑やかすぎる
- **重い独白**: 主人公の重い独白は light_recovery 禁則に該当
