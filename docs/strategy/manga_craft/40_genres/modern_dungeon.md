# 40. genre: modern_dungeon — 現代ダンジョン

genre_id: `modern_dungeon`
作品例: kindle-test-1「現代ダンジョンで最強になる物語 (缶詰ガチャ) Vol.1」

現代ダンジョン系特有の作法。`30_scenes/` の universal な作法に **追加 / 強化**
する形で適用する。

---

## 既存コードとの対応

`src/lib/manga/storyboard-v2/craft-guide-directives.ts` の `GENRE_DIRECTIVES["modern_dungeon"]`
と整合させること:

```typescript
modern_dungeon: [
  "【現代ダンジョン】SNS/配信動画/ニュース速報 panel を活用して『主人公の社会的影響』を可視化",
  "【現代ダンジョン】現代の生活感 (制服/コンビニ/スマホ) と異世界要素 (ダンジョン/魔物) のコントラストを panel 配置で強調",
],
```

本ファイルの内容で TS 側の文字列を更新する想定 (Codex 経由)。

## ジャンル必須要素 (L1 MUST 強化)

### 1. SNS / 配信 / ニュース反応で社会的影響を可視化
`30_scenes/social_reaction.md` の作法を **必須** で適用。1 巻に 5-10 回。
現代ダンジョン系では、世界が "現代日本" であることを SNS で明示する。

### 2. 現代の生活感 vs 異世界要素のコントラスト
1 ページ単位で「制服 / コンビニ / スマホ」と「ダンジョン / 魔物 / アイテム」を
**併置** する panel 配置を作る:
- 主人公が制服でダンジョン入り
- スマホでステータス画面を見る
- コンビニのおにぎりとドロップ品アイテムを並べて

### 3. キャラ紹介ボックス (intro_box)
重要キャラの初登場時に四角枠で「名前 + 属性 + 短い特徴」を 1 回掲載
(`30_scenes/chapter_opener.md` 参照)。1 巻あたり 5-8 回。

### 4. ステータス画面 panel
章末・章頭で必ず 1 回はステータス画面 panel を更新表示
(`30_scenes/item_analysis.md` 参照)。

### 5. アイテム説明枠
新規アイテム / スキル登場時は灰色背景の矩形枠で「名前 + 効果 + 価格」を別レイヤー
記述 (`30_scenes/item_analysis.md` 参照)。

## ジャンル推奨要素 (L2 SHOULD 強化)

### 1. 現代家族との対比
家族 (父・妹・母) との日常会話シーンを 1 巻に 3-5 回配置。異世界要素を
"非日常" に保つための装置。

### 2. 探索者ランキング / 階層概念
- 1 巻終盤に **海外ランキング王** のようなキャラを cliffhanger で初登場
- 「○○階層」の数値で進捗を可視化 (1 階層=雑魚、5 階層=ボス級)

### 3. 経済軸の強調
ドロップ品 = 換金 = 経済 という流れを 1 巻に 2-3 回。「時給 100 円」のような
expectation/reality ギャップで現実感を作る (`30_scenes/dialogue.md`)。

### 4. 配信者キャラの活用
妹 / 友人キャラを配信者にすることで、社会的反応を内部キャラで吸収できる。

---

## ジャンル禁則

### 1. 異世界転生要素を混ぜない
現代ダンジョンは「現代日本に異世界要素が来る」設定。**主人公が異世界転生してきた**
要素を入れると `isekai-tensei-cheat` ジャンルに混線する。

### 2. 中世ファンタジー描写を入れない
城・神殿・貴族・剣・馬車などは出さない。すべて現代日本の文脈で表現する。

### 3. SNS 不在の世界観に逃げない
「電波が通じない」「ダンジョン内ではスマホが使えない」設定で SNS 演出を
放棄するのは弱い。ダンジョン外で必ず SNS を使う場面を用意する。

## サブタイプの分類 (2026-05-06 追加)

`dungeon-modern` 内で **2 サブタイプ** が並立する。
作品設計時にどちらを採用するか先に決める。

### (A) 外部反応型 (subtype: external_social)

- 代表: **kindle-test-1** (現代ダンジョンで最強になる物語 / 缶詰ガチャ)
- ステータス UI: 簡素 (1 panel・章末/章頭で 1 回ずつ)
- 社会的反応: SNS / ニュース / 配信動画 panel を 1 巻 5-10 回
- 海外探索者: 1 巻終盤 cliffhanger で初登場
- 主人公装備: 制服のまま戦闘 (現代日本に異世界要素が来る世界観)

### (B) 内部 UI 型 (subtype: gacha_ui)

- 代表: **レベルガチャ Vol.1-3** (兎杜ちあ / 皇雪火)
- ステータス UI: 2 ページ全面見開き、スキル一覧詳細、数値 before/after 矢印、
  rarity 色分け、New マーカー
- 社会的反応: SNS panel 殆どなし、代わりに ガチャ rarity と数値で表現
- 海外要素: 殆どなし (内部進行で完結)
- 主人公装備: ダンジョン用甲冑 (RPG ゲーム的世界観)
- 装飾密度: kindle-test-1 より高い (キラッ・ジャララ等の効果音 + 斜めテキスト多用)

### (C) ハイブリッド (subtype: hybrid)

- 代表: 要選定
- (A) と (B) を半々で。最も難易度高、生成リスク高
- Phase A 試験では避けることを推奨

bible 設定で `subtype: external_social | gacha_ui | hybrid` を明示し、
storyboard-builder が場面別 directives を切り替える前提。

## 失敗パターン (現代ダンジョン特有)

### 共通

- **異世界要素過多**: ダンジョン内描写ばかりで現代家族 / 学校 / 街の描写が
  少ないと "ダンジョンファンタジー" になり、現代ダンジョンの魅力が消える
- **ステータス UI を入れない / 入れすぎ**: 入れないと "ゲーム感" が消える、
  入れすぎると "ゲーム実況系" に劣化

### (A) 外部反応型での特有失敗

- **SNS 描写が浅い**: 1 巻に 1-2 回しか SNS panel が出ないと、主人公の社会的
  影響が伝わらない
- **ステータス UI が肥大化**: 1 panel に納めるべきところを (B) 型のような
  2 ページ全面でやると、scene 軸のバランスが崩れる
- **海外要素を 1 巻外に置く**: 1 巻終盤の cliffhanger で海外の脅威を出さないと
  2 巻への引きが弱くなる

### (B) 内部 UI 型での特有失敗

- **ステータス画面が単純化**: 簡素な 1 panel 表示だと "ガチャゲーム感" が
  出ない。最低 2 ページ全面 + 詳細スキルリスト + rarity 表記が必要
- **ガチャ pull 演出の地味化**: 「キラッ」「ジャララ」等の派手な効果音 +
  斜めテキストパネルが無いと、ガチャの興奮が読者に伝わらない
- **数値 before/after 表記なし**: 「121」だけでなく「121 (←115)」のように
  成長を矢印で可視化しないと、レベルアップの実感が薄い
- **SNS panel を入れる**: SNS を入れると (A) 型に逆流し、(B) 型の純度が
  落ちる。社会的反応は内部 UI で完結させる

## 参考実例

### (A) 外部反応型: kindle-test-1

- **kindle-test-1** 「現代ダンジョンで最強になる物語 (缶詰ガチャ) Vol.1」(全 156p)
  - SNS / 配信 / ニュース速報: 1 巻で約 7 回
  - 家族との日常会話: 1 巻で約 4 回
  - ステータス画面 panel: 5 回 (各話末)、各 1 panel
  - アイテム説明枠: 約 15 回
  - 海外探索者の cliffhanger: 第 5 話で初登場 (ジャック)
  - 主人公装備: 制服

### (B) 内部 UI 型: レベルガチャ

- **レベルガチャ Vol.1-3** (兎杜ちあ / 原作 皇雪火 / キャラ原案 夜ノみつき)
  - 主人公: アマチショウタ / 天地翔太、年齢 21
  - SNS / 配信 / ニュース: ほぼ無し (3 巻通読でも確認できず)
  - ステータス画面: 2 ページ全面見開き、複数回登場、スキル一覧
    + 数値 before/after 矢印 + rarity 色分け + New マーカー
  - ガチャ rarity: R / SR / SSR の色分け、個数表記 (例: 「青(R)×5」「紫(SSR)×1」)
  - ガチャ pull 演出: 2 ページ見開き、「ジャララ」「キラッ」等の効果音
    + 斜めテキストパネル多用
  - 主人公装備: ダンジョン用甲冑 (現代と異世界要素のスイッチ)
  - マスコット: スライム/卵型キャラ (kindle-test-1 の PD と機能近似)

## 2 冊目精読 (2026-05-06 完了 — レベルガチャ Vol.1-3)

スクリーンレコーディング 3 本 × 各 60-70 秒の早送り通読 (1.5 fps サンプル抽出 +
コンタクトシート可視化方式) で実施。フル通読ではないため次の項目は後続精読で
深掘り対象とする:

1. ✅ **SNS / 配信頻度の差分**: 確認 — レベルガチャは SNS 殆ど不使用
2. ✅ **ステータス UI の使い方**: 確認 — 2 ページ全面型で頻繁登場
3. ❌ **章扉の構造**: 早送り動画では明確に確認できず、要追加精読
4. ❌ **現代生活描写の比重**: 学校 / 家族 / 街の描写量、要追加精読
5. ❌ **戦闘 panel の動作分割数の差**: 雑魚戦・ボス戦の panel 数比較、要追加精読
6. ❌ **cliffhanger 構造**: レベルガチャの巻末引き方が SNS 不使用でどう成立しているか
7. ❌ **海外要素の有無**: レベルガチャでは確認できず、要追加精読

### 次の精読の進め方提案

レベルガチャ各巻を **章扉だけ全数確認** する精読パスを別途用意する。
スクリーンレコーディングでは速度が早すぎて章扉が捕捉できなかったため、
ユーザーが各巻の章扉ページのみを個別スクショ提供する形式が効率的。
