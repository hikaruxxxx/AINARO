# 30. chapter_opener — 章扉

scene_id: `chapter_opener`
genres: `universal` (構造) + `dungeon-modern` (キャラ紹介ボックス)
function: `decoration` + `structure`

各話の **1 ページ目** に配置する 1 ページ全面の章扉。1 巻 5 話なら章扉も 5 回。

---

## L0 参照

- L0-1 (panel = 物語進行単位): 章扉も「これから読む話の感情を予告する」役割を負う
- L0-4 (静と動のリズム): 章扉は静側の極致 (1 panel 全面、密度低)

---

## L1 MUST

### 1. 1 ページ全面 = 1 panel
章扉は分割しない。1 panel で完結させる。複数 panel に割ると "扉" の機能が
失われ、本編との境界が曖昧になる。

### 2. 必須要素 4 点
- **章番号 + 章タイトル** (例: 「§2 話 自分専用のダンジョン」)
- **主人公全身** (フルポーズ、本作の代表的な姿)
- **マスコットの併置** (主人公とのサイズ・温度差を可視化)
- **タイトルロゴ or 作品ロゴ** (作品の世界観を示すロゴ)

### 3. 各話で 1 回 = 1 巻で 5 回
章扉は **必ず各話の冒頭に置く**。省略すると話の境界が読者に伝わらず、
"延々続く 1 本の漫画" の体感になり完読率が下がる。

---

## L2 SHOULD

### 1. 主人公の表情で章のトーンを予告
- 第 1 話 (世界観 establishing): 無表情・カメラ目線
- 第 2 話 (能力覚醒): 少し見上げ・期待
- 第 5 話 (cliffhanger 前): 厳しい表情・横顔

章扉の表情で「この話は何が起きるか」をぼんやり予告する。

### 2. 背景は装飾控えめ
背景に作品ロゴまたは無地・薄いグラデーション。装飾過多は読者の目を散らす。
silence_panel の発展形と捉える。

### 3. マスコットは小さく寄り添う
主人公の足元・肩・上部などに配置。主人公サイズの 1/3-1/5 程度で。
マスコットが主人公より大きいと "誰が主人公か" が伝わらない。

---

## L3 MAY

### 1. キャラ紹介ボックス (intro_box)
重要キャラ初登場の話の章扉に、四角枠で「名前 + 属性 + 短い特徴」を 1 回掲載。
1 巻あたり 5-8 回が目安。

例:
- 「壱野泰良 苦手なコト イカサマ扱い」
- 「ジャック ダンジョン探索者 換金額・世界ランキング王」

ジャンル `dungeon-modern` で特に多用される演出。`isekai-slowlife` 系では
省略されることが多い。

### 2. 章末ロゴ
章末の最終ページに作品タイトルロゴを再掲して区切り。章扉と対応するペア。
KDP では巻末でも使われる。

### 3. メタ説明 (マスコットの吹き出し)
マスコットが章扉の余白で「今回は○○の話だよ☆」のようなメタ説明を入れる
パターン。子供向け / コメディ寄り作品で多用。シリアス作品には不向き。

---

## 典型 panel 構成例

章扉は分割しないが、レイアウトのパターンが 3 種ある:

### パターン A: 中央配置
```
┌─────────────────────────┐
│   §2話 タイトル                       │
│                                              │
│           主人公全身                  │
│              ▲                                │
│           マスコット                    │
│                                              │
│        作品ロゴ (下部)              │
└─────────────────────────┘
```

### パターン B: 上下分割 (タイトル上、絵下)
```
┌─────────────────────────┐
│ §2話 タイトル (大文字)         │
├─────────────────────────┤
│           主人公全身                  │
│              ▲                                │
│           マスコット                    │
└─────────────────────────┘
```

### パターン C: キャラ紹介ボックス併置
```
┌─────────────────────────┐
│   §2話 タイトル                       │
│                                              │
│   主人公全身    ┌──────┐  │
│      ▲              │intro_box │  │
│   マスコット    └──────┘  │
└─────────────────────────┘
```

---

## 失敗パターン

- **章扉スキップ**: 「ページを節約して本編から入る」のは KDP コミックでは
  やってはいけない。読者は章扉でリセットして次話に入る感覚を期待している
- **章扉に panel 分割**: 章扉を 3-4 panel に分割すると "扉" の静謐さが消え、
  本編との境界が曖昧になる
- **マスコット巨大化**: マスコットが主人公より大きいと、読者が "主人公はこのキャラ"
  と誤認する
- **章番号なし**: タイトルだけで章番号が無いと、読者が "今何話目を読んでいるか"
  把握できない。読了率に直撃する

## 参考実例

### subtype: external_social (kindle-test-1 型)

- **kindle-test-1 第 1 話扉 (p006)**: 中央配置パターン。主人公制服、PD 足元。
- **kindle-test-1 第 2 話扉 (p039)**: 中央配置 + キャラ紹介ボックス併置パターン。

### subtype: gacha_ui (レベルガチャ型, 2026-05-06 Vol.1-3 精読で訂正)

#### 訂正経緯

初回スキム (動画ベース) で「本編章扉省略」と判定したが、per-page 精読により
誤りが判明。レベルガチャは **「第N話」表記の小さな枠 + 本編 panel 構成のハイブリッド型** を使う。
独立 1 ページ全面章扉ではないため動画俯瞰では見落とした。

#### ハイブリッド型章扉の構造

- **レベルガチャ Vol.2 spread 25** (第 8 話冒頭): 章扉ハイブリッドの典型
  - LEFT page 左上に小さい長方形枠で「**第8話**」(章番号 + 章タイトル無し)
  - 同ページ内にいきなり本編 establishing が始まる:
    - panel 1 (大コマ): 主人公全身ポーズ + マップ + 武器装備
    - panel 2-3: 主人公クローズアップ + セリフ
  - RIGHT page は establishing 続き (新階層の引き) + 主人公の独白
- 章扉単体での「主人公全身 + 章タイトル + マスコット」のような独立 1 ページは作らない
- 章扉と establishing が **完全に同居** することで巻のページ予算を圧縮 (1 巻 88 ページ)

#### 巻末 bonus section の独立章扉

- **レベルガチャ Vol.1 spread 85**: 「描き下ろし漫画」セクションのみ独立章扉あり
  - 白背景 + 細い斜線 grid 模様
  - 縦書き章タイトル枠「描き下ろし漫画」
  - マスコット (スライム) 3-5 体散布配置
  - 主人公全身は無し (= 軽量・装飾的)
  - サイズは見開き左半分のみ (右半分は bonus 本編開始)

#### opening establishing と章扉の関係

- **レベルガチャ Vol.1 spread 5** (本編冒頭): 第 1 話の章扉は独立配置されず、
  opening establishing 2 ページ見開きが章扉を兼ねる (「ダンジョン NO.777」
  「アンラッキーホール」のナレーション枠 4 個で世界観確立)

### subtype 別の章扉構造の比較

| 要素 | external_social (kindle-test-1) | gacha_ui (レベルガチャ) |
|---|---|---|
| 各話冒頭の独立章扉 | 1 ページ全面 (主人公全身 + マスコット + 章タイトル + ロゴ) | 「第N話」小枠 + 同ページ本編 establishing 開始 |
| 章扉の頻度 | 5 個/巻 (各話に 1) | 5 個/巻 (各話に 1、ただし軽量) |
| 章扉のページ予算 | 5 ページ消費 | 0 ページ追加消費 (本編に統合) |
| 巻末 bonus 章扉 | 不明 (要確認) | 「描き下ろし漫画」独立章扉あり |
| opening establishing | 章扉とは別配置 | 章扉と同ページで統合 |

bible 設計時に subtype を選んだ段階で章扉のページ予算が決まる。

## storyboard-builder への注入

scene_type = `chapter_opener` の時、subtype で注入を切り替える:

### subtype = external_social (default for kindle-test-1 型)

```
- 章扉は 1 ページ全面 = 1 panel で構成すること (分割禁止)
- 必須要素: 章番号 + 章タイトル + 主人公全身 + マスコット + 作品ロゴ
- 主人公の表情で章のトーンを予告 (シリアス話なら横顔・厳しい表情)
- 背景は装飾控えめ、silence_panel の延長として処理
- マスコットは主人公サイズの 1/3-1/5 で寄り添う配置
- 各話冒頭に必ず配置 (1 巻 5 話なら 5 個)
```

### subtype = gacha_ui (レベルガチャ型)

```
- 各話冒頭はハイブリッド型章扉を使用:
  - LEFT page 左上に「第N話」を小さな長方形枠で配置 (章タイトル無しでも可)
  - 同ページに本編 establishing を直接続ける (1 ページ全面章扉は作らない)
  - 章扉と establishing で 1 ページ完結
- 第 1 話のみ章扉を省略し、opening 見開き 2 ページ establishing で代替
  (大コマ + ナレーション枠 4-5 個で世界観確立)
- 巻末「描き下ろし漫画」「番外編」セクションには独立章扉を配置:
  - 白背景 + 細い斜線 grid 模様
  - 縦書き章タイトル枠
  - マスコット 3-5 体散布配置
  - 主人公全身は無し
  - 章扉サイズは見開き左半分のみ (右半分は bonus 本編開始)
```

L3 (intro_box, 章末ロゴ等) は genre = `dungeon-modern` の時のみ追加注入。
subtype 未設定なら external_social を default 適用。
