# 30. social_reaction — SNS / ニュース / 配信反応

scene_id: `social_reaction`
genres: `dungeon-modern` (主) + `isekai-tensei-cheat` (派生)
function: `worldbuilding` + `decoration`

主人公の活動が **世間にどう受け止められているか** を視覚 UI で示す場面。
ナレーション禁則 (L0-2) を回避しつつ、社会的影響を読者に体感させる。

---

## L0 参照

- L0-2 (ナレーション禁則): 世間の反応をナレーション枠で書かず、SNS 画面・
  ニュース速報・配信動画の **視覚 UI** で示す
- L0-1 (panel = 物語進行単位): SNS panel も 1 つの感情ビート (世間の驚き / 称賛 /
  批判) を運ぶ

---

## L1 MUST

### 1. 視覚 UI レイヤーで識別
SNS / ニュース / 配信は **スマホ画面の矩形フレーム** で囲む別レイヤーとして描く。
通常の panel 内に直接書かない。読者は「現実世界の反応」と瞬時に判別する。

### 2. プラットフォーム識別
どのプラットフォームかを読者が一目で分かるよう、視覚的に差別化:
- **Twitter/X 風**: 短文 + ユーザー名 + RT/いいね数
- **ニュース速報**: 見出し + 配信局名 + 速報マーク
- **配信動画**: 再生数 + コメント欄

### 3. 主人公の社会的影響が変化する場面で
SNS panel は **主人公の活動が世間に届いた瞬間** に置く。乱用すると意味が
希釈する。1 巻に 5-10 回が目安。

---

## L2 SHOULD

### 1. 数値で衝撃を示す
- 再生数: 「10 万回!?」のような驚きを誘発する数値
- いいね数: 急増を示す表記 (1 万 / 10 万 / 100 万)
- ニュース速報の「初!」「最高記録更新!」表記

### 2. 主人公のリアクションをセットで
SNS panel の前後 or 同ページに、主人公がスマホを見ているシーンを必ず置く。
「世間は驚いているが、主人公は冷静」の温度差を作るのが定石。

### 3. 複数視点の重ね合わせ
1 つの出来事に対して複数の SNS / ニュースを並べると、社会的広がりが伝わる:
- panel 1: Twitter で話題
- panel 2: ニュース速報で取り上げられる
- panel 3: 配信動画で解説される

ただし 1 ページに詰めすぎると目が散る。3 panel まで。

---

## L3 MAY

### 1. 否定的反応 / 炎上の演出
称賛だけでなく **批判 / 疑念** の SNS も混ぜると、世界が立体化する:
- 「本物?」「やらせでしょ」
- 競合プレイヤーからの牽制 RT

### 2. 配信者キャラの活用
妹や友人キャラが配信者だと、SNS panel が **キャラの活動 panel** にもなる。

例 (kindle-test-1):
- 妹 (青木) の配信動画 + 「D 映像編集者の資格を取る!」(瞳キラキラ)

### 3. 海外反応
外国語の SNS / ニュースで「世界規模での話題化」を示す。1 巻終盤や
cliffhanger 直前で使う。

例 (kindle-test-1 第 5 話・海外編):
- 海外探索者ジャックのチームが主人公の話題に触れる

---

## 典型 panel 構成例

### パターン A: SNS 起点 (場面導入と兼用)
- panel 1 (upper, 大コマ): スマホ画面・Twitter「ヤバすぎ」「再生数 10 万回」
- panel 2 (middle, 中ゴマ): 主人公がスマホを見ている自宅引き
- panel 3 (bottom, 近景): 主人公の表情・独白「まあ…そうなるか」

### パターン B: 戦闘後の SNS 拡散
- panel 1 (大コマ): 戦闘跡地の establishing (前ページの戦闘の余韻)
- panel 2 (上半分): Twitter「○○ダンジョンで異変!?」「主人公かっけぇ…」
- panel 3 (中ゴマ): ニュース速報「初の単独攻略者か」
- panel 4 (中ゴマ): 主人公独白 (冷静)
- panel 5 (引き): 次への展開

### パターン C: 複数視点の重ね合わせ (社会的広がり)
- panel 1 (上、横長): Twitter (一般人)「マジ?」「こいつ何者?」
- panel 2 (中、横長): ニュース速報 (公式)「探索者ランキング更新」
- panel 3 (下、横長): 配信動画 (解説者)「これは前代未聞ですね」
- panel 4 (右下、近景): 主人公がスマホ画面を見ている

### パターン D: 海外反応 (1 巻終盤)
- panel 1 (大コマ): 海外の街並み establishing
- panel 2 (中ゴマ): 海外探索者の手元のスマホ・英語 SNS
- panel 3 (中ゴマ): 海外探索者「日本にこんな奴が…」(緊張)
- panel 4 (引き): 海外探索者の表情 (cliffhanger 直前)

---

## 失敗パターン

- **SNS を panel 内の地の絵で書く**: 矩形フレームで囲む別レイヤーにしないと
  「画面 / 文字」と「現実 / 絵」の境界が曖昧になる
- **SNS 連発**: 1 ページに 5 個以上の SNS panel は情報過多
- **称賛一色**: 全 SNS が肯定的だと世界が嘘くさい。3-4 回に 1 回は
  否定 / 疑念を混ぜる
- **数値の控えめ表記**: 「再生数 1000 回」では衝撃が弱い。少なくとも
  10 万回 / 100 万回など読者を驚かせる桁
- **主人公リアクション省略**: SNS panel だけ置いて主人公がスマホを見ている
  場面が無いと、世間の反応と主人公の物語が分断される

## 参考実例

- **kindle-test-1 第 4 話**: スキル進化 → SNS でニュース化される流れ
- **kindle-test-1 第 5 話冒頭 (p127-130)**: 海外探索者 (ジャック) サイドの
  SNS / ニュース反応で 1 巻終盤の cliffhanger 構造を作る
- **kindle-test-1 妹 (青木) の配信**: 配信者キャラと社会的反応の融合例

### 反例: SNS panel を使わない dungeon-modern (2026-05-06 追加)

- **レベルガチャ Vol.1-3 全 3 巻**: 同じ `dungeon-modern` ジャンルだが
  SNS / ニュース / 配信 panel が殆ど存在しない。代わりに **ガチャ rarity 分類 +
  ステータス画面 + ガチャ結果数値** で社会的価値を表現する型 = "内部 UI 完結型"
- → SNS panel は dungeon-modern で **必須ではない**。"外部反応型" と "内部 UI 型"
  の 2 サブタイプが並立する

### サブタイプ別の代替手段

| サブタイプ | 代表作 | 社会的反応の表現 |
|---|---|---|
| **(A) 外部反応型** | kindle-test-1 (缶詰ガチャ) | SNS / ニュース / 配信 panel + 海外探索者の cliffhanger |
| **(B) 内部 UI 型** | レベルガチャ Vol.1-3 | ガチャ rarity (SSR) / ステータス数値 / Skill Level Up 表示 |
| **(C) ハイブリッド** | (要選定) | 両方を半々で。最も難易度高 |

(B) を選ぶ作品は SNS panel の作法 (`L1 MUST`) を **scene_type = item_analysis** に
吸収させる形になる。

- (kindle-vol-4 待ち: 異世界転生系では SNS が無い世界観のため、
  「噂話」「酒場での話題」「貴族会議」が代替する想定)

## storyboard-builder への注入

scene_type = `social_reaction` の時:

```
- SNS / ニュース / 配信は矩形フレームの別レイヤーとして描く
- プラットフォームを視覚的に識別 (Twitter/X 風、ニュース速報、配信動画)
- 数値で衝撃を示す (再生数 10 万回、最高記録更新 等)
- SNS panel の前後に主人公がスマホを見ているシーンを必ず配置
- 称賛と疑念を混ぜる (3-4 回に 1 回は否定的反応)
- 1 巻に 5-10 回が目安、1 ページに 5 個以上は情報過多
- 1 巻終盤では海外反応で世界規模の話題化を示す (cliffhanger 直前)
```

`bible.subtype = gacha_ui` (内部 UI 型) の作品では:

```
- SNS panel は使わない。代わりに 30_scenes/item_analysis.md の
  ステータス画面 / ガチャ rarity 表示で社会的価値を表現
- 「外部の世間の声」は省略可。読者は「rarity SSR を引いた」だけで主人公の凄さを認識する
```

genre = `dungeon-modern` でも `subtype` 次第で必須/不要が変わる。
`isekai-slowlife` `isekai-tensei-cheat` (中世風世界) では SNS は使わず代替手段
(噂話・酒場・宮廷) で表現する。
