# AINARO i18n対応計画（日本語・英語）

## Context
AINAROサイトは現在日本語のみ。UIテキスト（~90文字列、15+ファイル）を日英対応にする。
小説コンテンツ（Supabase）の翻訳はスコープ外。UIクロームのみ。

## 方針
- **next-intl** + App Router `[locale]` セグメント
- URL: `/ja/...`, `/en/...`（常にprefix付き）
- ブラウザ言語で自動検出・リダイレクト
- admin/apiルートはi18n対象外（日本語のまま）

## 実装順序

### 1. next-intl導入 + 設定ファイル作成
- `npm install next-intl`
- `src/i18n/config.ts` — locales定義（ja, en）
- `src/i18n/request.ts` — getRequestConfig（メッセージファイル読み込み）
- `src/i18n/navigation.ts` — createNavigation（locale-aware Link/Router）
- `next.config.ts` — createNextIntlPlugin でラップ

### 2. middleware作成
- `src/middleware.ts` — locale検出 + リダイレクト
- matcher: `/((?!admin|api|_next|_vercel|.*\\..*).*)`

### 3. 翻訳辞書作成
- `src/messages/ja.json` — 全日本語テキストを構造化抽出
- `src/messages/en.json` — 英語翻訳

名前空間: metadata, header, footer, bottomNav, novel, episode, genre, status, format, pages, notFound, about, contact, privacy, terms

### 4. ディレクトリ再構成（一括）
- `src/app/layout.tsx` → 最小ルートlayout（`return children`のみ）
- 既存全ページを `src/app/[locale]/` 配下に移動
- `src/app/[locale]/layout.tsx` — html lang動的化、NextIntlClientProvider、フォント設定
- admin/, api/ はそのまま

移動対象:
```
page.tsx, not-found.tsx, globals.css,
novels/**, new/, ranking/, genre/, tag/,
about/, contact/, privacy/, terms/, mypage/
```

### 5. コンポーネント更新
各コンポーネントでハードコード文字列を `t(...)` に置換:

| ファイル | 種別 | 文字列数 |
|---------|------|---------|
| Header.tsx | client | 4 + 言語切替追加 |
| Footer.tsx | server | 5 |
| BottomNav.tsx | client | 4 |
| EpisodeReader.tsx | client | ~15 |
| NovelFeedCard.tsx | client | 2 |
| ContinueReadingButton.tsx | client | 1 |
| NovelCard.tsx | server | 2 |
| GenreBadge.tsx → client化 | 10 |
| StatusBadge.tsx → client化 | 3 |

Linkは全て `@/i18n/navigation` のlocale-aware Linkに置換。

### 6. format.ts locale対応
- `formatPV`, `formatCharCount`, `formatRelativeTime` に locale引数追加
- 英語: K/M表記、Intl.RelativeTimeFormat使用
- 日本語: 既存ロジック維持

### 7. LanguageSwitcher作成
- `src/components/layout/LanguageSwitcher.tsx`
- Headerのナビ領域に配置
- 現locale表示 + クリックで切替（`router.replace(pathname, { locale: next })`）

### 8. SEO対応
- 各ページのgenerateMetadataでhreflang alternates追加
- sitemap.ts: 両locale分のURL生成
- Interフォント追加（英語locale用）

## 注意点
- client componentは `useTranslations`、server componentは `getTranslations`
- Header/BottomNavのパス検出regex: `next-intl`の`usePathname`はlocale prefixなしを返すので既存regexそのまま動く
- 法的ページ（terms, privacy）: `t.rich()` でHTML構造付き翻訳
- GenreBadge/StatusBadgeはclient化してuseTranslations使用
- EpisodeReaderのrouter.pushは `next-intl`のuseRouterに置換

## 検証手順
1. `/` → ブラウザ言語に応じて `/ja/` or `/en/` にリダイレクト
2. `/en/` — UI英語、小説コンテンツは日本語のまま
3. `/ja/novels/slug/1` — 日本語読書体験
4. `/en/novels/slug/1` — 英語UI + 日本語小説テキスト
5. 言語切替ボタンでパス維持したまま切替
6. `/admin/` — 影響なし（日本語のまま）
7. `/api/` — 影響なし
8. ページソース: `<html lang="...">` + hreflangタグ確認
9. `npm run build` 成功確認
