# 文体プロファイル：偽装同居は契約の外側で

## パラメータ

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.15
inner_monologue_ratio: 0.30
description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称の静かな独白調。短めの文を重ね、触覚・温度・匂い・音といった身体感覚の描写で感情の麻痺と回復を示す。直接的な感情語を避け、コンビニおにぎりの味・カフェオレのぬるさ・名刺のエンボスといった具体物で心情を語る。比喩は抑制的で、会話文は短く断定的。ネガティブな疲弊感と微かな希望の両方を同じトーンで滑らかに接続する。
