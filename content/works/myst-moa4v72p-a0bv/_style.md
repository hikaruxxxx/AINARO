# 文体プロファイル：廃病院供養録 怨念喰らいのドライバー

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.05
inner_monologue_ratio: 0.30
description_density: high
humor_level: low

vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

短文を改行で刻み、一文一語の独立行で恐怖の間を演出。五感描写が濃密で、消毒液と腐敗の混合臭、湿った指の油跡、ひやりとした合皮の感触など触嗅覚を多用。擬音「ぽたり」「ぱた」を単独行に置く演出が反復。回想と現在を匂いで接続し、心理の揺らぎと外部の異変を交互に積み重ねる構成。
