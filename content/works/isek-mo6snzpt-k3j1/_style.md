# 文体プロファイル：神域解析の観察者

```yaml
pov: first_person
tempo: medium

```

## 文体の特徴

一人称の内省的モノローグを骨格に、短文と長文を緩急つけて配置。五感描写を「鼻が先に、背中が遅れて」のように順序を解体して提示し、認識のズレから異世界感を演出。ステータス板は全角スペース整形で視覚的に区切る。比喩は控えめで、身体感覚（骨盤・奥歯・肋骨）に落とし込む描写が特徴的。観察者から当事者への内面変化を丁寧に追う。
