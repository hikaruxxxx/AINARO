# 文体プロファイル：観察者の死角

## パラメータ

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.20
inner_monologue_ratio: 0.30
description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称の内省を主軸に、五感の細密描写（匂いの層、指先の温度、コンマ単位の時間）で観察者の知覚を可視化。短文と読点を多用したリズム。比喩は思弁的で、教室を「舞台装置」と捉える距離感。シャープペンや窓の光など小道具で心情を翻訳し、声の震えを物理現象として刻む文体。
