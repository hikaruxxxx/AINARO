# 文体プロファイル：半径ゼロメートルの私と王子様

## パラメータ

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.15
inner_monologue_ratio: 0.30
description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称の内省主体で、短いセンテンスと体言止めを重ねてリズムを作る。視覚・聴覚・触覚の細部描写（机の木目、シャープペンの感触、シャンプーの匂い、上履きの爪先）を積み、主人公の閉じた内面を感覚で可視化する。ダッシュや改行で間を置き、地の文と独白を滑らかに往還する静謐な筆致。
