# 文体プロファイル：首都高レクイエム

## パラメータ

```yaml
pov: third_person
tempo: fast
sentence_length_avg: 18
dialogue_ratio: 0.30
inner_monologue_ratio: 0.15
description_density: medium
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

短文を畳みかける硬質でハードボイルドな文体。速度計・心拍・呼吸など計測的ディテールで臨場感を作り、回想は五感の断片(焦げたトースト、火葬場の扉の音)で刻む。インカム越しの台詞は無駄がなく、比喩は乾いて抑制的。「食事は燃料。睡眠は整備。感情は弾倉」のような体言止めで主人公の内面を圧縮する。
