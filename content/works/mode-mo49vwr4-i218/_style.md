# 文体プロファイル：放課後、壁際のきみへ

## パラメータ

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.15
inner_monologue_ratio: 0.30
description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称の内省が密度高く、身体感覚(指の震え・喉の凍り・壁の冷たさ)で感情を描く。短い体言止めと「ガリ、ガリ」のような擬音で呼吸を刻み、比喩は刃・棚の箱など内面寄りの質感で統一。夕陽・ニスの匂いなど五感情報を丁寧に積み、地の文が会話より優勢で、セリフは最小限の一言が重く響く構造。
