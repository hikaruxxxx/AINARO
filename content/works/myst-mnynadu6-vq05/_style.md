# 文体プロファイル：八度目のミオ、ルーシアの檻

## パラメータ

```yaml
pov: third_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.25
inner_monologue_ratio: 0.15
description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称に近い三人称視点で、ミオの感覚と思考を緻密に描写する。冷たさ・湿度・音の反響など五感の微細な描写が豊富で、無機質な船内の静寂を際立たせる。短文と長文を組み合わせ、違和感や不穏さを読者の皮膚感覚に訴える文体。比喩は詩的だが過剰にならず、心理描写は直接的な説明を避け行動と感覚で示す。
