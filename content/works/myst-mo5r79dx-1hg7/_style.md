# 文体プロファイル：拳の墓標、妹の日記

```yaml
pov: third_person
tempo: fast
sentence_length_avg: 18
dialogue_ratio: 0.25

description_density: medium
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

短い文を重ねるハードボイルド。五感描写(鉄錆の味、雨の匂い、タイルの冷気)で臨場感を作る。三点リーダーと一行空白で沈黙と間を演出。独白と回想を差し挟み、格闘描写は秒単位で刻む。台詞は最小限、核心を突く一語で余韻を残す。過去と現在を映像的にカットバックで繋ぐ構成。
