# 文体プロファイル：復讐回路 NEMESIS

```yaml
pov: third_person
tempo: fast

dialogue_ratio: 0.20

description_density: medium
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

短文・体言止めを多用したハードボイルド調。「サイレン。」「ひとり。」など一語一文で緊張感を刻む。五感描写（鉄錆の匂い、タイヤの金切り声、汗で滑るシフトノブ）が密度高く、車載シーンで速度・距離・回転数の数値を即物的に提示。比喩は最小限、過去回想は短いカットバックで挿入。ハンドリングのプロ感と、内面の独白の硬質さが同居する文体。
