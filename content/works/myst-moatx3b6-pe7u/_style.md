# 文体プロファイル：関わるな、と老人は言った

```yaml
pov: first_person

description_density: high

```

## 文体の特徴

一人称視点で五感に密着した描写が濃密。嗅覚(線香・菊と白檀・錆びた鉄)、触覚(ひやりと湿った染み)、聴覚(畳を擦る音の律動)を重ねて恐怖を積み上げる。短文と読点の多い文節で呼吸を刻み、「ざ、ざ、ざ」等の擬音を効果的に挿入。地の文に淡々と異常を混ぜる静かな筆致で、合理化しようとする内面独白と現象の不可解さの対比が不穏さを生む。
