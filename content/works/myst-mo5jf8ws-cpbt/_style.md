# 文体プロファイル：四時四十四分、鍵は開いていた

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.15

description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称の内省と五感描写を密に織り交ぜ、短文と体言止めで緊張を刻む。匂い・軋み・光の輪といった感覚情報を反復させ、同じ単語を呟き直すことで疑念の揺らぎを可視化する。「——」「、」を多用した息継ぎが怪異と記憶の境界を曖昧にし、日常的な仕草と不穏な違和感を等価に並べる、静かに侵食する文体。
