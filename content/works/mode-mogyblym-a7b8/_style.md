# 文体プロファイル：ぼっちの俺が孤高の天才に溺愛されてバドの相棒になった件

## パラメータ

```yaml
pov: first_person
tempo: slow
sentence_length_avg: 28
dialogue_ratio: 0.15
inner_monologue_ratio: 0.30
description_density: high
humor_level: low
tension_curve: wave
vocabulary_level: standard
line_break_frequency: frequent
```

## 文体の特徴

一人称の内省的な語りで、上履きの音、床板のきしみ、汗の感触といった身体感覚と微細な聴覚描写を積層する。比喩は「教室という小さな海」「ガラス一枚向こう側」など距離感のあるもの。短文と長文を混ぜ、改行を多用してリズムを作る。心拍や呼吸を句読点で刻み、心理の揺れを物理現象として描く。擬音(ぱしっ、こん、きゅ)を効果的に配置。
